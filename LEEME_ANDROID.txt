================================================================================
  🚧 PROBLEMA CONOCIDO: ACCESO DE RED
================================================================================

SÍNTOMA:
  - Django corre correctamente en WSL
  - Pero NO es accesible desde Windows ni desde teléfono

CAUSA:
  - Django está en WSL2 (red virtualizada)
  - WSL tiene su propia red interna
  - No es accesible desde la red WiFi directamente

SOLUCIÓN (solo para teléfono físico):
  - Configurar port forwarding de WSL a Windows
  - Ver: INSTRUCCIONES_WSL_NETWORK.md
  - Script automático: configurar_wsl_portforward.ps1

ALTERNATIVA (más fácil):
  - Usar el EMULADOR de Android Studio
  - El emulador mapea automáticamente 10.0.2.2 → 127.0.0.1
  - No requiere configuración extra
